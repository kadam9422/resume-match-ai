# Release Notes

## v1.0.0

Initial public release of ResumeMatch AI.

### Included features
- Resume upload for PDF, DOCX, and TXT files
- Login and registration flow
- AI-assisted job role analysis
- Match score and feedback summary
- Skills, strengths, and improvement suggestions
- Resume history tracking
- Modern React frontend and Express API

### Tech stack
- Node.js
- Express
- MongoDB
- React + Vite
- Gemini API integration

### Notes
- Local demo mode is supported when MongoDB is not available
- Production deployment can be configured with Render or similar hosting providers
